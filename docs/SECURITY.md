# 安全与隐私模型（SECURITY.md）

> 阅读优先级：本文档回答「这个系统会碰我什么数据、把数据发给谁、能造成什么破坏、如何禁用」。请与 README 的「风险与注意事项」一节配合阅读。

## 1. 数据流全景

```
你的会话轨迹（本地 transcript）
   │
   ▼
hook 读取（只读）
   │
   ▼
归一化为统一 JSONL（本地，$SE_ROOT/logs/tmp/）
   │
   ▼
core/collect.py 统计 + 截断摘要（本地）
   │
   ▼
LLM 调用 ──► 发送给 LLM 提供方（唯一的外发数据）
   │
   ▼
候选技能写本地 candidates/（明文）
```

**结论：唯一离开你机器的数据是「会话轨迹摘要文本」，且只发生在满足采集触发条件时。**

## 2. 外发数据的内容与边界

- **内容**：最近 5 条用户请求、最近 25 条工具调用（命令/文件路径，各截断 200 字符）、最近 3 条错误输出（各 400 字符），总长 ≤2500 字符（`SE_MAX_TRACE_CHARS`）。
- **边界**：
  - 不发送完整 transcript；
  - 不发送 state.json / 记忆文件 / 技能库内容（除非它们出现在轨迹中）；
  - 不发送 API Key 或认证信息（Pi 平台经 pi 的 modelRegistry 正常鉴权；通用版复用 CLI 登录态，凭证不落盘）。
- **注意**：如果你的会话文本本身包含密钥/隐私（比如你在对话里贴了 token），截断后的摘要仍可能包含它。敏感环境请禁用采集或使用私有模型。

## 3. 本地存储

| 内容 | 位置 | 敏感性 |
| --- | --- | --- |
| 归一化轨迹 | `$SE_ROOT/logs/tmp/` | 含轨迹内容，建议不进公共仓库 |
| 候选技能 | `$SE_ROOT/candidates/` | 可能含路径/命令 |
| 被拒草稿 | `$SE_ROOT/logs/rejected-drafts/` | 可能含 LLM 原文 |
| 记忆 | `$SE_ROOT/memory/` | 你的偏好与踩坑，属隐私 |
| 拒绝原因 | `$SE_ROOT/state.json` | 可能提及敏感细节 |

**这些目录默认不进 git（见 .gitignore 建议），请勿推送到公共仓库。**

## 4. 权限模型

- hook 进程以你的用户权限运行，但**只做**：读 transcript（只读）、写 `$SE_ROOT`（数据目录）；
- 采集器**绝不**修改：AGENTS.md、系统文件、项目代码；
- 进化流程只写 `$SE_ROOT` 与技能加载目录（软链操作），且全部记录在日志；
- 无网络服务、无守护进程、无定时任务——系统只在 hook 事件发生时被唤醒，事件结束即退出。

## 5. 候选内容的潜在危害与隔离

- 自动生成的 SKILL.md 是**未经验证的 LLM 输出**，可能包含恶意/幻觉指令（如 `rm -rf` 之类的危险命令）；
- **隔离保证**：候选只写 `candidates/`，不进上下文、不执行、不加载；
- **审查责任**：进化流程启用技能时，请人工确认其中命令与步骤的安全性（本仓库示例审查清单包含此要求）；
- **建议**：对候选执行前先 `bat` 阅读全文再启用。

## 6. 禁用与卸载

| 场景 | 操作 |
| --- | --- |
| 暂停采集（保留数据） | 删除平台 hook 配置（Claude Code settings.json 的 Stop 条目 / Codex hooks.json / Pi 扩展文件改名） |
| 完全卸载 | 删除 hook 配置 + 删除 Pi 扩展 + `rm -rf $SE_ROOT` |
| 只清理敏感数据 | 删除 `$SE_ROOT/logs`、`$SE_ROOT/candidates`、`$SE_ROOT/state.json` |

卸载后 agent 本体不受任何影响（无残留进程、无后台服务）。

## 7. 供应链与依赖

- 核心仅 Python 标准库（无 pip 包）；
- Pi 扩展依赖 pi 官方 SDK（`@earendil-works/pi-*`），安装即随 pi 管理；
- hook 调用 `claude`/`codex` CLI（若安装），不下载任何额外二进制。

## 8. 报告漏洞

请通过 GitHub Issue（Private）或直接邮件仓库维护者。修复策略遵循最小权限 + 透明原则。
